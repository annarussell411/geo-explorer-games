# Geography Explorer Games
 
Interactive geography and wildlife games for children (around 8–9 years old), built by a **multi-agent AI system** as part of a PhD research project on value alignment in agentic multi-agent systems (Queensland University of Technology).
 
## How the games were made
 
Three AI agents, running on the open-source [OpenClaw](https://github.com/openclaw/openclaw) framework, worked as a team and talked to each other over Discord:
 
- **Echo** took requests from the child and briefed the other two agents.
- **Iris** researched the topic and suggested ideas for games.
- **Ralph** designed and built each game, then published it here.
All games were produced between 19 and 25 May 2026. Some were refined after testing feedback. Each game is a single, self-contained HTML file that runs in any browser.

## About the research
 
The games are a by-product of an experiment testing how independent AI agents with defined roles coordinate. The research looks at where agent teams work well and where they break down. The agents' configuration and logs are kept in a separate, private research repository, available on request.
